# feeder

## Workflow

Run linters and tests before committing or creating a PR to catch issues early.

## Commits

- One logical change per commit (atomic commits)
- Commit message: one short line, no body

## Attribution

Never add authorship or tooling attribution (e.g. "Generated by Claude Code",
"Co-authored-by: Claude", "🤖") to PR titles, PR descriptions, commit
messages, code comments, issue comments, or anywhere else in the repository.

## Pull Requests

Use `.github/pull_request_template.md` for all PR bodies. When running `gh pr create`, pass its content via `--body`.
Drop the `References` section from the PR description when it would only contain the empty placeholder.
